# Codex 手机助手 CN 0.4.0-cn1

**构建来源：** nokryong/mobile-codex v0.4.0, GPL-3.0；保留源代码许可、声明以及第三方版权信息。独立定制版，不属于 OpenAI 官方产品。

## 已实现
- 使用原版 Android Codex 引擎、ChatGPT 登录、多账户、模型设置、Codex 使用额度、项目文件、终端、MCP/Skills。
- 通过 Android 无障碍服务读取界面、点按、输入、滑动、打开应用；控制有明确启用开关和停止按钮。
- 简体中文界面：系统语言自动识别或在 设置 → 通用 → 语言 → 简体中文 选择。已翻译主要标签；暂未覆盖的文案回退英文，绝不翻译用户和模型内容。
- 账户与使用额度中增加 **查看官方 Credits 余额** 按钮：浏览器跳转 ChatGPT 网站，进入 设置 → 使用情况 查看实际余额。账户使用百分比不冒充货币/积分余额。
- 独立安装包名 `app.annyee.codexcn`，不覆盖原版 Mobile Codex。

## 未完成 / 限制
- **未集成 Shizuku 控制器**：手机控制仍使用安卓无障碍功能。需要用户开启该权限并在设置中启用；Android 限制、密码页、锁屏、敏感应用等不保证可操控。
- Credits 没有通过非公开接口直接抓取数值；该版只提供官方入口。
- 本构建流水线用一次性密钥签名，因此未来构建不能直接覆盖升级，必须自行备份数据并卸载旧包或改用持久密钥的签名流程。
- 未进行真实手机上的登录、控制和兼容性验证。编译通过不能等同于全部运行正常。
- 由于含 Codex 运行时，本 APK 体积较大；仅适配 Android 10+ ARM64。

## 安装步骤
1. 下载 `Codex-CN-0.4.0-arm64.apk`，直接安装（独立包名）。
2. 打开 App → 连接 ChatGPT 账户 → 浏览器设备码授权。
3. 进入 设置 → 工具 → 手机控制 → 打开安卓无障碍并启用控制。
4. 进入 设置 → 账户 查看 Codex 额度，或点击官方 Credits 查询入口。
5. 想关闭手机操控时，使用屏幕停止按钮或软件里的控制开关。
